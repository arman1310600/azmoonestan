# آزمونستان AI — راهنمای نصب و استقرار

پلتفرم هوشمند آموزشی داخل سایت «سنجش | دبیرستان دورهٔ دوم خاتم» — فقط پایه‌های ۱۰ تا ۱۲ (دورهٔ دوم).

## ۱. پیش‌نیازها

- Node.js / Bun (پروژه Next.js 16 App Router)
- SQLite (فایل `db/custom.db` — بدون سرور جدا)
- دسترسی به سرویس GLM از طریق `z-ai-web-dev-sdk` (بدون کلید اضافه در سندباکس)

## ۲. نصب

```bash
bun install
# ساخت جداول آزمونستان (در کنار جداول موجود سایت — تخریبی نیست)
bun run db:push
# بذر برنامهٔ درسی دورهٔ دوم: پایه ۱۰/۱۱/۱۲ × ۳ رشته × درس‌ها × فصل‌ها (هدف ۳۰ سؤال برای هر فصل)
bunx tsx scripts/seed-az-curriculum.ts
# اجرا
bun run dev
```

## ۳. متغیرهای محیطی (.env)

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `DATABASE_URL` | `file:.../db/custom.db` | پایگاه داده SQLite |
| `AUTH_SECRET` | مقدار توسعه | رمز امضای نشست |
| `ZAI_MODEL` | `GLM-5.3-Flash` | مدل اصلی گفت‌وگو |
| `ZAI_VISION_MODEL` | `glm-4.5v` | مدل دید و درک ویدیو/تصویر |
| `ZAI_API_KEY` / `ZAI_BASE_URL` | — | فقط برای اتصال بیرونی اختیاری |

نمونهٔ کامل در `.env.example`.

## ۴. ابزارهای سمت سرور

- `pdftotext` / `pdfinfo` (poppler-utils) — استخراج متن مرکز اسناد PDF. نبود آن فقط اسناد اسکن‌شده را به «نیازمند بررسی» می‌فرستد.
- OCR: فعال نیست — در مرکز یکپارچه‌سازی با وضعیت «نیازمند کلید» ثبت شده (بدون ادعای دروغ).

## ۵. ایجنت خودمختار

- ضربان داخلی هر ۲۰ ثانیه (اولین تیک با اولین درخواست به APIهای آزمونستان آغاز می‌شود — وابسته به مرورگر مدیر نیست).
- چرخش مأموریت‌ها: بدهی آزمون ← [تولید سؤال ⇄ ویدیو ⇄ بازبینی ⇄ تحلیل معلمان] با نشانگر گردشی.
- بدهی آزمون: به‌محض ۱۵ سؤال بلااستفاده در هر درس، آزمون خودکار ساخته و منتشر می‌شود.
- خطای ۴۲۹: ۴ تلاش با عقب‌نشینی (۵/۱۵/۴۰ ثانیه برای مدل، ۲.۵/۷/۱۸ برای ابزارها)، فیوز ۳ ضربه‌ای با ۳ دقیقه استراحت، عقب‌نشینی نمایی خودپرنده (سقف ۳۰ دقیقه)، بازیابی خودکار با ضربان.
- توقف/ادامه: مرکز فرماندهی ← «توقف» یا «فعال‌سازی» (PATCH `/api/az/agent/jobs`).

## ۶. REST API نسخهٔ ۱

- سند OpenAPI: `GET /api/az/openapi`
- مسیرها: `/api/v1/grades | subjects | chapters | questions | exams | videos | sources | agent/jobs | admin/overview`
- احراز هویت: نشست سایت یا هدر `x-api-key` (کلیدها در تنظیمات با کلید `az_api_keys`).
